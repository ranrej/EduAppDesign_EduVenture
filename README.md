# 🌳 EduVenture - A Fun Way to Learn Math! 🎲

**Project for CSCI 4080U - Edu. App Design**

EduVenture is an interactive, **forest-themed** math learning app designed to make arithmetic fun and engaging for children aged **6 to 9**. Through structured lessons, exciting games, and an **Escape Room challenge**, EduVenture helps young learners develop strong math skills while having fun! 


## 📌 Features  

### 🎓 **Learn Math Concepts**  
- Step-by-step tutorials for **addition, subtraction, multiplication, and division**.  
- Interactive exercises with **instant feedback** to reinforce learning.  
- A **gamified experience** to make learning enjoyable.  

### 🎮 **Math Games Section**  
- **Minute Math** ⏳: Solve problems quickly under a time limit.  
- **Balloon Pop** 🎈: Pop the right balloons with correct answers.  
- **Lunch Time** 🐵: Help the monkey get its bananas by solving equations.  
- **Matching Game** 🧩: Match numbers to their correct math expressions.  

### 🏆 **Escape Room Challenge**  
- Solve **math-based puzzles** to progress through levels.  
- Unlock new challenges while sharpening problem-solving skills.  
- A mix of **adventure and education** to keep kids engaged.  

### 🎨 **Forest-Themed UI**  
- Beautiful **kid-friendly** interface with nature-inspired visuals.  
- **Easy navigation** with large, visually appealing buttons.  
- **Progress tracking** to keep kids motivated.

## 🚀 Getting Started  

### **Prerequisites**  
Make sure you have the following installed:  
- [Flutter](https://flutter.dev/docs/get-started/install)  
- Dart SDK  
- Android Studio / VS Code (with Flutter plugin)  

### **Installation**  
1. Clone the repository:  
```sh
   git clone https://github.com/ranrej/EduVenture.git
   cd eduventure
```
2. Install dependencies:
```sh
   flutter pub get
```
3. Run the app:
```sh
   flutter run
```
